Settings

The wallet software list and the keys. Each section saves on its own.

Never enter seed phrases, private keys, PINs, passwords, wallet secrets, or contact details.

01 / Wallet software

Wallet software

Every entry is a wallet software choice for the keys you check. The list is saved as a whole, so add an entry before you remove the last one. A name that already comes from a cloud key is not needed here, and names must be unique.

Removing an entry never changes a saved check: the software selected in an earlier check stays as it was recorded. Removing an entry also closes the alerts that software raised, such as software that no longer supports the hardware. A blocked key becomes available again as soon as its alert is closed.

02 / Key rotation

Key rotation

This is where the keys themselves are changed. The name and the model or service are only labels, so they can be changed here on their own. A rotation records that a key has been replaced by a new one, keeps or changes its name, may give the replacement the other type, and closes the alerts that the key raised. No earlier check is changed.

The address path is part of the identity of a key. It can be changed here while the key has no saved check. The address path must change when the key is rotated. Every key needs its own new path, and no other key may already use it.

The type is part of the identity too, so the setup locks it. Changing it means the key is a new one, which is why the choice is only offered together with a rotation. A key that becomes a cloud key offers its own name as a wallet software choice, so a name the list above already holds has to be removed first.

Rotating a key creates a new wallet. Move your funds from the old multisig setup to the new one, and verify that the new setup works, before you rely on it.

Do not discard the old keys or the old seed backups until the funds have been moved and confirmed. Losing access to the old setup before the move can mean losing the bitcoin.
