01 / Keys

Keys

The name is only a label, so it can be changed at any time. The type and the address path are the identity of the key: the type is locked, and the address path can only be changed while the key has no saved check.

02 / Wallet software

Wallet software

Every entry is a wallet software choice for the keys you check. The list is saved as a whole, so add an entry before you remove the last one. A name that already comes from a cloud key is not needed here, and names must be unique.

Removing an entry never changes a saved check: the software selected in an earlier check stays as it was recorded.

03 / Key rotation

Key rotation

A rotation records that a key has been replaced by a new one, keeps or changes its name, and closes the alerts that the key raised. The type and the address path are locked, and no earlier check is changed.

Rotating a key creates a new wallet. Move your funds from the old multisig setup to the new one, and verify that the new setup works, before you rely on it.

Do not discard the old keys or the old seed backups until the funds have been moved and confirmed. Losing access to the old setup before the move can mean losing the bitcoin.
