First-run setup

Key setup

Choose how many keys your multisig setup has and how many of them are required to sign, then name each key, choose its type, and record its address path. The name is a label you can change later in the settings; the type and the address path are locked once the setup is saved.

Never enter seed phrases, private keys, PINs, passwords, wallet secrets, or contact details.

01 / Multisig setup

Threshold and key slots

The threshold is how many keys are required to sign. The key slots are how many keys the setup holds. The app records check results only — it never signs anything.

02 / Keys

The keys

The name you enter is the product name of that key everywhere: the check form, the alerts, the history, and the CSV export. Names must be unique.

A hardware key is a device you hold yourself. A cloud key is held by a provider; its own name is also offered as wallet software for the other keys.

The address path is the public derivation path the key is used at, for example m/48'/0'/0'/2'. It is the identity of the key, together with its type, and it holds no secret.
