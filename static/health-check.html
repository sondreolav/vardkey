02 / Key

Key check

One or more keys have an open alert. A key with an open alert cannot get a new check until the alert is closed, because the alert is closed by the user and not by a newer check.

    Open the dashboard to close the alerts

    One submission records one key. The other keys keep their own next check date.

    A blocked key is marked in the list and cannot be selected. The other keys can still be checked.

    The recorded address path is compared with the path stored for the key, and the result is recorded automatically.

    Loading key profiles…

    The address path does not match the one stored for this key. Check it against your BSMS and try again, or confirm that you want to record this check anyway.

    A check recorded anyway keeps the address path, the key note, the contact confirmation, and the overall comment. The hardware, the software, and the security results cannot be recorded, and the check raises a critical alert.
